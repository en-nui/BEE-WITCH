This repo contains code for "Evolutionary dynamics within the honey bee gut microbiome" by Chris R. P. Robinson, Adam G. Doleza, and Irene L. G. Newton. Submitted code is unpolished and highly "bespoke". I (CRPR) am happy to answer any questions or provide a clean, more general workflow upon request for any of the analyses carried out in the MS. A good deal of the code was generated by a combination of ChatGPT and Gemini, and I am incredibly grateful to those doing work in the human microbiome (Nandita Garud, Ben Good, etc) for establishing a lot of the methodology with which I use in this paper.
